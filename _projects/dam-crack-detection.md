## Dam Crack Defect Intelligent Recognition

**Role:** Project Lead, responsible for system architecture and algorithm framework design.

The project was commissioned by Huadong Engineering Corporation. It encompasses both system development and algorithm research, with three core modules:

- **Crack Detection** &mdash; A sequence network-based method for detecting dam surface cracks
- **Crack Segmentation** &mdash; Precise pixel-level segmentation of detected crack regions
- **Crack Measurement** &mdash; Quantitative measurement of crack dimensions (length, width)

The designed crack detection method has been **patent-pending**, with related papers and software copyrights in preparation.
